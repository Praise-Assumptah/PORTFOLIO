# Praise Assumptah portfolio (static site)

Files: index.html, css/style.css, js/main.js, uploads/ (your photo, CV, certificates, project screenshots).
No backend, no build step. Open index.html in a browser, or host the folder on GitHub Pages or Netlify.
Add your files to uploads/ using the names in uploads/README.txt. To change text, edit index.html.
